# Chart Cooking Simulator

This dumb game is about designing recipes in a chart. Then you cook automatically. 
Sorry for the bad code quality, I have written most of the code in two days and
generally didn't care about code quality. It's here only to store it somewhere
and I made it public only because why not.

## How to play

Gameplay guide including how to play is at our [wiki](https://github.com/IvanCepicka/chart-cooking-sim/wiki).
